# 考研英语十年真题单词本

基于考研英语（一）2010–2025 与考研英语（二）2010–2024 历年真题提取制作的单页离线/在线单词本（纯静态单文件 `index.html`，零外部构建依赖）。

## 在线访问

- **主域名**：<https://www.8569badminh2h.xyz/>（`8569badminh2h.xyz` 自动 308 跳转至 `www`）
- **备用域名**：<https://kaoyan-english-wordbook.vercel.app/>
- 支持 URL Hash 直达熟词生义模块：`/#poly`

## 收录内容

- **动介词组**：历年共 **687** 个（近十年 **605** 个），覆盖短语动词、动介搭配、三词短语；支持高频榜单与核心动词族、介词、考频、英一/英二、考研进阶、完形直接挖空、含熟词生义多维筛选及真题原句展开。
- **单词熟词生义**：历年共 **673** 个（近十年 **448** 个），提供常见熟义与考研生义对照、硬核生义筛选及真题语境例句。

## 核心学习功能

- **背词管理**：收藏、标熟「斩词」与恢复（含 FLIP 列表动画与撤销提示），学习进度与主题偏好自动保存至浏览器 `localStorage`（按域名隔离）。
- **自测模式**：背词遮挡模式（点击或悬停揭晓释义）、双模块闪卡自测（桌面端支持空格翻面与 `←`/`→` 切题，移动端支持左右手势滑动）。
- **界面体验**：Soft Editorial 视觉风格、桌面/移动端自适应布局、日间/夜间模式切换与打印排版优化。

## 数据分析（Google Analytics 4）

已集成 GA4 v2 学习行为分析（衡量 ID：`G-57NXVD9C6X`）：

- **用户与行为追踪**：用户进度与设备分层属性、学习里程碑（`study_milestone`）、统一筛选与零结果搜索诊断（`apply_filter` / `search`）、闪卡会话汇总（`flashcard_session_end`，含离页 `beacon` 上报）、误触撤销监控（`undo_action`）。
- **数据防污染参数**：

  - `?ga_debug=1`：开启 GA4 DebugView 实时调试
  - `?no_track=1` / `?no_track=0`：在当前浏览器持久化开启或关闭自用免统计

## 本地使用与部署

- **离线使用**：浏览器直接打开 `index.html` 即可。
- **线上部署**：在项目目录执行 `vercel --prod` 即可发布至 Vercel。
